# Отчёт 1. Градиентный спуск и стратегии выбора шага

## Цель

Исследовать, как стратегия выбора шага, критерий остановки и начальная точка влияют на градиентный спуск на функциях с разной геометрией.

## Что исследовано

- тестовые функции Ackley, Booth и Eggcrate;
- экспоненциальное и обратное затухание шага;
- адаптивная корректировка шага;
- критерии остановки по норме градиента, изменению аргумента и значению функции;
- линейный поиск по условию Армихо;
- дополнительные функции Plateau, Rastrigin и конечное приближение Weierstrass.

## Основные наблюдения

- На выпуклой функции Booth все рассмотренные варианты быстро приближаются к единственному минимуму.
- На мультимодальных функциях результат заметно зависит от стартовой точки: локальный метод может стабильно сойтись не к глобальному минимуму.
- Экспоненциальное уменьшение шага дало лучший баланс точности и устойчивости в базовой серии экспериментов.
- Обратное затухание часто требовало существенно больше итераций.
- Поиск Армихо сокращал число итераций на отдельных ландшафтах, но не устранял проблему локальных минимумов.

## Как открыть результат

Откройте [ноутбук](../notebooks/01_gradient_descent.ipynb) непосредственно на GitHub или локально через JupyterLab. Все итоговые графики встроены в файл и доступны без выполнения ячеек.

## Ограничение воспроизводимости

В переданном исходнике вычислительные ячейки были пустыми. Поэтому ноутбук можно воспроизвести как отчёт с сохранёнными визуализациями, но нельзя полностью пересчитать по команде **Run All**. Для строгого повторения эксперимента необходимо добавить исходные реализации функций, градиентного спуска, стратегий шага и генерации графиков.

Рекомендация для следующей версии: восстановить код из оригинальной рабочей среды и зафиксировать seed, параметры каждой серии и версии библиотек.
