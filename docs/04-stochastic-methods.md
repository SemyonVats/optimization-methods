# Отчёт 4. Стохастическая и популяционная оптимизация

## Цель

Исследовать методы, способные покидать локальные минимумы, и сравнить их с локальными алгоритмами из предыдущих работ.

## Реализация

- Simulated Annealing с настраиваемой начальной температурой, скоростью охлаждения, длиной шага и числом итераций;
- Particle Swarm Optimization с инерцией, когнитивным и социальным коэффициентами;
- эксперименты на функциях Rastrigin, Eggcrate и Booth;
- применение имитации отжига к комбинаторной задаче N ферзей;
- визуализация траекторий, динамики целевой функции и конфигурации доски.

## Основные результаты

- Медленное охлаждение и высокая начальная температура помогли simulated annealing лучше исследовать мультимодальные ландшафты, но были избыточны для простой выпуклой функции.
- В проведённой серии PSO оказался точнее и стабильнее simulated annealing на Rastrigin и Booth.
- Коэффициенты притяжения частиц существенно влияют на баланс исследования и преждевременной сходимости.
- На выпуклой задаче локальные детерминированные методы остаются более экономичными.
- В задаче N ферзей имитация отжига нашла бесконфликтную конфигурацию, но потребовала большого числа итераций.

## Воспроизведение

```bash
pip install -r requirements.txt

```

Откройте [ноутбук](../notebooks/04_stochastic_optimization.ipynb), перезапустите ядро и выполните все ячейки. Точный номер итерации в стохастических задачах может измениться при другом seed или версии NumPy; сравнивать следует качество решения и общую динамику, а не побитовое совпадение вывода.

Расширенная серия и задача N ферзей выполняются дольше базовых демонстраций.
